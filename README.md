# Bhargav Raikar | Portfolio

Personal portfolio of Bhargav Raikar, Chemical Engineer (B.E. 2027, UICT Jalgaon) and National Award Winner, Smart India Hackathon 2025 (AIR 1).

Built with plain HTML, CSS and JavaScript in a single file (`index.html`), so there is no build step.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The complete website |
| `Bhargav_Raikar_Resume.pdf` | Resume linked from the Resume buttons |

## Run locally

Open `index.html` in any browser.
